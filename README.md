# 💊 DrugSense AI (Flutter App)

DrugSense AI is a smart medicine assistant mobile/web application built using Flutter.
It allows users to identify medicines, extract text from images, and get AI-powered responses.

---

## 🚀 Features

* 🔐 User Authentication (Login & Register)
* 💬 AI Chat Interface
* 📷 Image Upload for Medicine Detection
* 🧠 AI-based Response using Backend APIs
* 🗂 Chat History Support
* 🌐 Works on Web & Mobile

---

## 🛠 Tech Stack

* **Frontend:** Flutter (Dart)
* **Backend:** Spring Boot (Java)
* **Database:** MySQL
* **OCR:** Google Vision API
* **AI:** Gemini API
* **API Communication:** REST APIs

## ⚙️ Setup Instructions

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/drugsense-ai.git
cd drugsense-ai
```

---

### 2️⃣ Install dependencies

```bash
flutter pub get
```

---

### 3️⃣ Run the app

```bash
flutter run
```

---

## 🔗 Backend Configuration

Make sure your backend is running at:

```
http://localhost:8080/api
```

Update base URL in:

```
lib/config/app_config.dart
```

---

## ⚠️ Important Notes

* This project requires backend setup (Spring Boot)
* API keys (Google Vision & Gemini) are not included for security reasons
* Ensure proper environment configuration before running
